# Changelog

## [1.0.1] - 2026-09-25

- Fixed compatibility with Flutter < 3.27 by replacing `withValues()` with `withOpacity()`.

## [1.0.0] - 2026-09-25

- Initial release of `name_screen_flutter`.
- Floating badge showing current screen / route name.
- 1-tap clipboard copying with animated feedback ("Copied!").
- Freeform dragging across the screen to avoid obscuring action buttons.
- Full compatibility with `NavigatorObserver` (GoRouter, AutoRoute, Navigator 1.0/2.0).
- Option to filter out unnamed modal popups & dialogs.
- Highly customizable styling and configuration (`NameScreenConfig`).
